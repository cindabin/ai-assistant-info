Privacy Policy

Last updated: August 2026

This application (“AI Assistant”) is a personal automation tool with a single user: its developer. It is not distributed publicly and does not process data for anyone other than its own developer/operator.

What data it accesses

Using Google’s gmail.modify OAuth scope, the app reads inbox message metadata and content, and can apply labels, archive, or send email on the user’s own behalf.

How data is used

Email content is sent to Google’s Gemini API to classify each message (e.g. “needs a reply” vs. purely informational) and, for the daily digest feature, to generate a short summary. Classification results are used immediately to apply a Gmail label or compose a digest email; message content is not stored by the app beyond the duration of that single operation, and is not shared with any party other than Google (as the host of both the Gmail and Gemini APIs used).

Data retention

The app does not maintain its own copy or database of email content. The only persistent state it keeps is a small local run log (success/failure of past automated runs) and the label/organizational changes it makes directly in the user’s own Gmail account.

Third parties

No data is sold, shared with advertisers, or used for any purpose other than performing the triage/digest actions described above. The only external service involved is Google (Gmail API and Gemini API).

Revoking access

Access can be revoked at any time via Google Account → Security → Third-party access.
